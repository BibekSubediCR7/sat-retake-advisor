# Common Data Set fill-in sheet

Schools whose SAT numbers aren't verified yet. The site shows "Data not yet verified" for them until this is filled in.

**How to fill it in:** open the link, find the section named below, and copy the numbers **exactly as printed**. Leave a line blank if the CDS doesn't print it, and never estimate. When you're done, send this file back (or paste it in chat).

**Where things are in a Common Data Set:**
- **C1:** "Total first-time, first-year … who applied" and "… who were admitted". Use the **Total** rows (or add the printed columns if no total is printed, and say so).
- **C9:** "Percent submitting SAT scores", then the SAT table with 25th / 50th / 75th percentile for **Composite**, **Evidence-Based Reading and Writing**, and **Math**.
- **C21:** Early Decision closing date(s) (ED I, ED II).
- **C22:** Early Action closing date, and whether it's restrictive.
- **C14 (or C21–C22 area):** Regular Decision application closing date.
- **Data year:** on the cover (e.g. 2025-26). **Class:** which fall the SAT table describes (usually printed above C9, e.g. "Fall 2025").
